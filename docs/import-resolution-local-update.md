# 2026-11-01 本地功能更新

当前仅更新本地应用。2026-11-02 已按用户提供的 sarScene 2.0 XML 增加字段读取；GitHub 推送和 Windows/Ubuntu 安装包发布仍暂缓。

## 重复导入

原始影像、独立样本和上传的回波按文件 SHA-256 内容判断重复，限定在当前项目内。改名不影响判重，同名不同内容可正常导入。

- 使用原本记录：返回原记录，保留其名称、字段、标注和样本，不重新生成影像预览。
- 作为副本导入：创建新记录及独立文件，不覆盖旧记录。
- 更新信息导入：更新原记录的录入信息并保留 ID；原始影像保留原图、预览和关联标注。样本与回波使用更新后的名称保存文件，样本编号保持不变。
- 取消：停止本次导入；原始影像会清理本次上传分片和合并文件。

原始影像在分片合并时计算哈希，选择后复用已合并文件。旧独立样本首次参与判重时流式补充内容哈希；缺失的原文件无法补算。桌面单进程后端串行执行判重和插入。回波仿真保持原来的创建行为，导入其相同文件时会提示。

## 空间分辨率

原始影像库和样本库均提供可清空的分辨率筛选，并可与其他条件组合。`1m`、`1 m`、`100cm`、`1000mm` 等归为同一选项。未知值单列为“未知”；无单位值、二维距离/方位值不转换成单一米数。

独立上传样本可填写分辨率。关联样本留空时跟随来源影像当前分辨率，来源字段修改后筛选和导出随之更新；显式填写时以样本自身字段为准。旧关联样本同样回退到来源影像。

## 样本导出降采样

单个样本在“导出”菜单中选择“降采样 N m（原格式）”。批量导出先选择顶部导出分辨率，再选择文件格式。默认保留原分辨率；目标仅有 0.5m、1m、2m、3m、5m，且必须严格大于每个样本当前的空间分辨率。未知、无单位或二维分辨率不能降采样。批量选项取本次导出范围的共同有效选项，勾选或筛选结果变化后再次校验。默认“勾选样本”，在表格左侧选择一个或多个样本；也可明确切换到“全部筛选结果”。按钮始终显示范围和数量，隐藏的样本不会随勾选导出。

后端会重新校验目标值。使用面积加权平均降低像素宽高；原格式 TIFF 保留数值类型及通道，可视化 TIFF/PNG/JPEG 在平均后生成显示图。降采样输出名包含目标分辨率；原样本文件及记录不变。非 RGB 的多通道 TIFF 转成显示图时使用第一通道，原格式 TIFF 保留全部通道。

## 原文件名与数据库升级

新上传原始影像在 `raw/<影像ID>/` 中保留上传文件名，非法字符被替换，超长名称截短；完整原文件名仍保存在元数据中。已有 `source.tif` 等内部文件名不自动改动，避免影响既有路径及关联。

SQLite 启动时补充样本 `resolution`、`checksum_sha256` 两列，首次补列前保存 `sar.db.before-sample-import-metadata.bak`。PostgreSQL 使用迁移 `20261101_0009`。应用资源更新前保留原 resources 备份，更新过程不复制或清空业务 data。

## 配套 XML（2026-11-02）

桌面版选择原始影像或样本后自动查找同目录 XML：优先同名（不区分扩展名大小写），其次匹配 `(2)` 等副本后缀；无同名匹配但目录仅有一份 XML 时读取该文件并提示核对。多份无法确定时提示手动选择；也保留手动替换和无 XML 手填。自动查找只读取所选文件的同级目录，不递归搜索。浏览器环境无法取得本地目录时使用手动选择。

支持用户确认的 `sarScene schemaVersion="2.0"` 结构：名称、数据源、卫星、频段、极化、开始/结束时间、时间基准、米制空间分辨率、影像宽高和经纬度。无地区等字段时需手填；原始影像的分辨率、地区、卫星、频段、极化和名称为必填。XML 替换和移除只清理仍未被手工改动的自动值；切换影像时清理旧 XML，晚到的旧查找结果不覆盖新文件。原始 UTC 时间保留微秒，手动改时间则使用输入值。

原始 XML 原字节保存在 `data/storage/sar/raw/<影像ID>/<原图名>.xml`，原 XML 文件名另存数据库，可从影像详情打开。原 XML 用于追溯；人工修改的有效字段保存在数据库，生成样本 XML 时使用当前字段。禁止外部实体，文件不超过 2 MiB。特定卫星入口与 XML 卫星不符时需改用对应入口或原始影像管理。

特定卫星入口增加“高分三号”，并使用“齐鲁一号星”“珞珈二号01星”；旧路由 ID 保留，旧卫星名称在显示及筛选时归一。

## 样本命名与 XML

新上传、裁切保存的样本使用 `类别_频段_分辨率_编号`，如 `舰船_X_0.5m_0001.tif`；最内层原图、缩略图和同名 XML 均使用该名称。编号在当前项目中自动分配，至少四位，超过 9999 自然扩展，避免截断重号。再次保存同一样本保留编号。

单个和批量导出均为 ZIP，内含影像及同名 XML；文件名和 XML 写入实际导出分辨率与像素尺寸。降采样示例：`舰船_X_2m_0001.tif` 和 `.xml`。原格式 TIFF 保留数值类型和通道。旧样本在导出时自动分配编号；历史业务文件路径不做批量迁移。

样本 XML 包含类别、编号、频段、分辨率、像素尺寸及可用元数据。有来源时附带来源影像 ID、原图经纬度与裁切 ROI；原图经纬度置于 `sourceImage` 内，不冒充样本足迹。回波的最内层数据及预览改用记录名，例如 `回波一.dat`、`回波一_amplitude.png`；编辑名称后同步改名。

SQLite 首次补充 XML、样本频段/编号字段前保存 `sar.db.before-scene-xml-metadata.bak`；PostgreSQL 对应迁移 `20261102_0010`。

## 标注尺寸

按住 Shift 绘制正方形，矩形旁实时显示原图像素宽高。尺寸标签优先放在框下方，随旋转手柄位置和画布边界避让。点击尺寸标签直接在原位置输入整数宽高，Tab 切换宽高，Enter 或离开输入区域确认，Esc 放弃本次尺寸修改；不再弹出窗口。超出原图范围时提示调整，保留原几何。旋转与缩放画布不改变像素尺寸。按住鼠标中键或空格拖动画布，中键不会改变当前标注位置。画完后使用侧栏的“完成标注”面板，避免遮挡画布，可继续调框和改尺寸，填好类别再保存；下次默认使用上一次类别。Esc 取消当前草稿。裁切保存自动按上述规则命名并生成 XML。

多边形样本按顶点轮廓裁切：PNG、可视化 TIFF 和缩略图保留透明外部区域；JPEG 不支持透明，外部填黑；原格式数值 TIFF 保持精度并将外部置零。样本预览使用棋盘格显示透明区域，旧 PNG 样本直接使用含透明通道的原样本预览，避免旧 RGB 缩略图恢复轮廓外内容；无需重新上传。

## 数值 TIFF 的备用读取与拉伸

桌面运行环境无法用主读取器解码部分 LZW TIFF 时，Pillow 备用路径保持 F/I/I;16 的原数值，再计算分位数并转成 8 位显示图。16 位整型仅为兼容缩放先转成无损容纳其数值的 float32；不先转 RGB，以免大于 255 的数据截白。原始 TIFF 不改动。旧版本已生成的全白缓存可备份后按相同 ID、路径和像素尺寸重建，无需重新上传，不改变已有标注和样本关联。

## 筛选联动与历史样本导出

原始影像库和样本库的下拉选项按当前关键词及其他筛选条件联动，当前筛选项自身保留可替换的值。清除条件后恢复相应选项。标题、说明、菜单等界面文字不可选中；输入框、表格数据、详情值和错误信息仍可选择复制。

原格式导出优先按完整原图和几何重新裁切，以保留源数值；若历史样本缺少标注几何、来源记录或原图文件，则原样导出已经保存的样本文件，不再强制重新生成。备用文件是什么格式就导出该格式，不将旧 PNG 冒充数值 TIFF，也无法补回旧样本已丢失的精度。降采样在实际导出的样本文件上执行，影像及同名 XML 写入实际尺寸、格式和目标分辨率。样本文件本身也缺失时返回包含样本名称和 ID 的中文错误，批量导出不会静默跳过失败样本。

## 大幅 TIFF 预览与失败重试

Pillow 备用预览与尺寸读取按文件头识别普通 TIFF 和 BigTIFF，使用 TIFF 专用读取器，支持超过通用图片像素阈值的 SAR 栅格。普通图片仍保留原有阈值，浮点和 16 位数值先缩小、拉伸后生成显示图，原 TIFF 不改动。已用 24444×24303、594062532 像素的 16 位 LZW TIFF 验证六级预览及原图哈希。

原始影像库中失败记录显示“重新生成预览”。更新后可直接使用已有原文件重新处理，无需重新上传，保留原影像 ID、元数据、关联标注及样本；缺少原文件时会继续提示失败原因。


## 上传前查重、分块预览与筛选置顶

点击“确定上传”先读取 TIFF 产品标签，单视复数/IQ 产品提示“不支持上传单视产品”。普通无符号多通道、单通道幅度影像仍可录入，不按卫星名称直接拦截。已入库失败记录重新生成预览时也使用同一提示。

原始影像先在本机按 2 MiB 分块计算 SHA256：桌面版使用系统流式读取，浏览器和生成的 Blob 使用 Worker，均不把整个文件放入内存。按当前项目、内容指纹和大小提前查重；“使用原本记录”和“更新信息导入”直接返回已有 ID，无原图分片传输，更新信息保留原图、标注、样本和预览关联，配套 XML 可一并更新。“作为副本导入”进入新记录上传流程，并把选择带到完成阶段，避免重复弹窗。完成上传后仍以服务端计算的指纹检查并发重复。

独立样本和回波也在发送文件前查重；选择复用时直接读取已有记录。历史独立样本缺少指纹时按保存的原文件补充，不对预览计算指纹。其他项目的记录不参与提示。

压缩 TIFF 使用内置 imagecodecs 按瓦片/条带解码，边读边采样到最多 8192 像素长边的预览，不生成整幅解压数组。已验证 186172×91283 的 16 位 LZW 珞珈影像，生成六级预览，原文件 SHA256 不变；本机该次验证峰值约 1.2 GiB。备用 Pillow 路径限制大幅 TIFF 的整图解码，避免重新走入内存溢出的路径。

原始影像、样本和回波筛选框支持点击图钉置顶，拖动置顶项手柄排序，或聚焦手柄后使用上下方向键。置顶按钮不改变当前筛选值；各筛选框分别保存本机顺序，重启后恢复。联动筛选暂时隐藏的选项仍保留置顶顺序，恢复可选时按原顺序显示。点击已置顶项的图钉可取消置顶。

上传摘要中的宽高统一显示为“影像尺寸”，其值取自配套 XML 的影像宽高字段。
